### Step 1: Use a mcp client to authenticate to Zepto

```
npx -y mcp-remote https://mcp.zepto.co.in/mcp
```

All is well if the authentication passes and you see "Connected to remote server using StreamableHTTPClientTransport".

### Step 2: Look around in the mcp

```
npx -y @modelcontextprotocol/inspector
npx -y mcp-remote https://mcp.zepto.co.in/mcp
```

You will see this in the terminal

```
Proxy established successfully between local STDIO and remote StreamableHTTPClientTransport
```

And a browser page opens up for the mcp inspector. Add a new server with 

Transport: stdio
Command: npx
Arguments:
-y
mcp-remote
https://mcp.zepto.co.in/mcp

Open Tools tab and look around
